Hi, welcome to my repository! Most of these projects, from compilers and interpreters to web apps, were created before AI came into our lives :) It's been an exciting ride, and I can't wait to see everything that will be possible with AI.

## Live demos

Old projects brought back to life: each one runs in the browser or shows real results generated by CI.

### Compilers and interpreters

| Project | What it is | Stack |
|---|---|---|
| [iguana-frita](https://github.com/andreanicte02/iguana-frita) · [demo](https://andreanicte02.github.io/iguana-frita/) | Compiler for J#, a Java-like language, to three-address code, with an optimizer and a 3AC interpreter | TypeScript, Jison |
| [python3d](https://github.com/andreanicte02/python3d) · [demo](https://andreanicte02.github.io/python3d/) | Python subset → intermediate language T → three-address code, with every stage shown | C#, Irony |
| [cql-interpreter](https://github.com/andreanicte02/cql-interpreter) · [demo](https://andreanicte02.github.io/cql-interpreter/) | Cassandra-like query language with an in-memory DBMS, types and procedures | C#, Irony, Blazor WebAssembly |
| [pollo-frito](https://github.com/andreanicte02/pollo-frito) · [demo](https://andreanicte02.github.io/pollo-frito/) | Interpreter for an R-like language: vectors, lists, matrices and functions | Java, JFlex/CUP, JavaCC |
